# 🚗 India New Car Buyer Guide (2026)

An interactive, single-page comparison tool for people buying a new car in India in the ₹7–16 lakh range. Built to cut through showroom confusion and help a buyer match a car to their **actual roads, budget, and priorities** — not marketing.

## What it does

- **Sortable / filterable comparison table** of 20+ popular cars (Maruti, Honda, Tata, Hyundai, Skoda, Mahindra, Nissan, Kia) — price, mileage, ground clearance, crash rating, boot, width, resale, 10-year cost-to-own, ADAS.
- **Ground clearance chart** — visualises why 198 mm vs 163 mm matters on bad roads.
- **Price ladder** — where each car sits on CSD on-road price.
- **10-year cost-to-own chart** — the real cost, including fuel and depreciation, not just sticker.
- **Decision framework** — smooth-highway vs rough-road profiles.
- **"Find your car" quiz** — 5 questions → a data-backed shortlist.
- **Buyer FAQ** — on-road price, CSD scheme, extended warranty, turbo vs NA, li-ion hybrid, seat-cover/airbag safety, hill-start, resale, SUV vs sedan.

## About the prices

Figures are **CSD (defence canteen) on-road, Pune basis**, captured from real dealer quotes and the AFD portal in mid-2026. **Normal showroom on-road prices run ~10–15% higher** (CSD waives part of the GST/cess). Use these as a **relative** comparison; confirm exact figures for your city and scheme with the dealer. Mileage shown is realistic city/highway, not ARAI.

## Tech

A single self-contained `index.html` — no dependencies, no build step, no server. Vanilla HTML/CSS/JS. Open the file in any browser, or host it as a static site.

## Run it

```bash
# just open the file
open index.html
```

To host (static site): upload `index.html` to GitHub Pages, Netlify, Vercel, or any static host.
